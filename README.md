# Fast Drivers' HUB

>Fast drivers' Hub is a web application for a kind of group that provides good and portable with fast transporting drivers services. The application will allow users to book rides and join selected and interesting trips. Application data was fetched from the fastX API.

## ADDITIONAL DESCRIPTION ABOUT THE APPLICATION

The Fast drivers' Hub consists of cars, drivers, and the My Profile section.

### Cars
The car section displays a list of current car drivers available for booking.

![cars List](https://i.pinimg.com/736x/89/99/3d/89993d349d40c8820ce6495c0e302e7e.jpg)
![Reserved drivers List](https://gooddrivers.ca/wp-content/uploads/2022/11/malte-helmhold-LGpqewNMGdg-unsplash-1536x1024.jpg)

### TRIPS

The Trips section displays a list of current trips along with their brief description and participation status. There is also a button next to each trip that allows users to join the selected trip or leave the trip the user joined earlier.

![TRIPS LIST](https://www.shutterstock.com/shutterstock/photos/2756641109/display_1500/stock-photo-black-car-driving-on-asphalt-road-motion-blur-effect-2756641109.jpg)
![Joined trips List](https://alphacarhire.com.au/wp-content/uploads/2025/10/Batch-2-Alpha-Car-Hire-Blogs-13.png)


### My Profile

The My Profile section displays all reserved rockets and space missions.

## Getting Started

To get a local copy up and running follow these simple example steps.

1. Clone the repository using

```
git clone https://github.com/KingsleyIbe/ben-kings-react-project.git
```

2. cd into the cloned repository

```
cd ben-kings-react-project
```

3. You now have the access to the files on your local machine!

#### Optional steps

Install the node_modules/ folder to be able to locally run the linter commands. Run:

```
npm install
```


To check Stylelint linter errors run:

```
npx stylelint "**/*.scss"
```

To check ESLint errors run:

```
npx eslint .
```
